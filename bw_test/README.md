# 흑백 그래프 디지타이징 (`bw_test`)

색이 없는 **흑백 논문 그림**에서 유전상수(ε)–온도(T) 곡선을 읽어 **엑셀로 저장**하는 예제입니다.

상위 폴더의 `read_permittivity_plot.py`는 **곡선을 색으로 구분**하기 때문에, 곡선이 모두 검은색인 옛 논문 그림에는 쓸 수 없습니다.
이 폴더는 그 문제를 해결하려고 만든 방법입니다.
**곡선마다 대략적인 경로(가이드)를 사람이 정해 주면, 프로그램이 그 근처의 실제 검은 선을 따라가며 값을 읽습니다.**

---

## 빠른 실행

```powershell
cd bw_test
python make_excel.py
```

설치 방법은 상위 폴더 [README](../README.md)의 "설치"를 보세요.

실행하면 다음 파일이 만들어집니다(이미 만들어진 것이 저장소에 들어 있습니다).

- `검증_Fig1.png`, `검증_Fig2a.png`, `검증_Fig2b.png`, `검증_Fig2c.png`: 읽은 점을 원본 위에 색깔로 표시한 확인용 이미지

## 대상 그림

고순도 BaTiO₃ 세라믹의 입자 크기(grain size)에 따른 유전상수–온도 그래프 두 장입니다.

| 파일 | 내용 |
|---|---|
| `fig1_BaTiO3_grainsize.png` | **Fig.1** 입자 크기 1.1 / 1.5 / 2.2 / 3.0 / 13 / 53 µm, −150~190 °C |
| `fig2_BaTiO3_3transitions.png` | **Fig.2** 1.1 µm vs 53 µm, 세 상전이 근처 확대 (cooling / heating) |
| | (a) 입방정↔정방정, 90~140 °C |
| | (b) 정방정↔사방정, −20~40 °C |
| | (c) 사방정↔능면정, −120~−55 °C |

Fig.2 읽는 법: **실선 + 빈 마커(← 화살표) = cooling**, **점선 + 채운 마커(→ 화살표) = heating**

## 동작 원리

### 1. 축 보정 (`calib.py`)
- 그래프 테두리 안쪽의 **짧은 눈금**을 픽셀에서 자동으로 찾았습니다.
- 그 위치를 축 값과 1차식(값 = a × 픽셀 + b)으로 맞췄습니다.
- 맞춤 잔차는 온도 0.18 °C 이하, ε 10 이하입니다.

| 그래프 | 1 px당 온도 | 1 px당 ε |
|---|---|---|
| Fig1 | 0.97 °C | 24.6 |
| Fig2a | 0.17 °C | 21.0 |
| Fig2b | 0.21 °C | 21.2 |
| Fig2c | 0.21 °C | 21.3 |

### 2. 곡선 추적 (`trace.py`)
1. 곡선마다 **가이드 경로**(대략적인 꺾은선)를 지정합니다.
2. 가이드를 따라가며 각 **열**(column)에서, 가이드 위아래 `W` 픽셀 안에 있는 검은 픽셀 덩어리를 찾습니다.
3. 그중 **가이드에 가장 가까운 덩어리의 중심**을 그 온도에서의 곡선 위치로 기록합니다.
4. Tc 근처처럼 선이 **거의 수직인 구간**은 열 대신 **행**(row) 단위로 같은 방법을 씁니다(`mode='y'`).
5. 라벨 글자나 화살표처럼 곡선이 아닌 검은 부분은 `ignore` 영역으로 뺍니다.

가이드가 조금 어긋나도 실제 선 픽셀에 맞춰지기 때문에, 가이드는 **대략**만 맞으면 됩니다.
곡선끼리 몇 픽셀 안으로 붙어 있는 곳에서는 가이드가 정확해야 합니다.

### 3. 정리 (`make_excel.py`)
- 따라간 점들을 **일정한 온도 간격**으로 보간했습니다. 간격은 Fig1 2 °C, Fig2a 0.5 °C, Fig2b·c 1 °C입니다.
- 급경사(행 단위) 구간은 **ε 약 250 간격**으로 저장했습니다.
- 그래프마다 시트 하나에 데이터와 **엑셀 차트**를 넣었고, `설명` 시트에 방법, 오차, 주의점, 곡선별 요약을 넣었습니다.

## 한계와 주의점

- **선 위의 값입니다.** 측정점(마커) 위치가 아니라 마커를 잇는 선을 읽은 값입니다.
- **읽기 오차**(선 두께 ±1~2 px 기준):
  - Fig1: 약 ±2 °C, ±50 ε
  - Fig2: 약 ±0.4 °C, ±40 ε
- **Fig1의 가운데 곡선 4개**(1.5 / 2.2 / 3.0 / 13 µm)는 −140~20 °C와 Tc 근처에서 서로 겹쳐서 구분할 수 없습니다.
  - 그래서 구분되는 **26~88 °C 구간만** curve A~D로 읽었습니다.
  - A = 1.5 µm는 그림 라벨로 확인했습니다.
  - B·C·D = 2.2·3.0·13 µm는 **추정**입니다. 라벨 위치와 "입자가 클수록 ε가 작아지는" 경향을 근거로 했습니다.
- **Fig1의 53 µm**는 −135~−90 °C에서 다른 곡선과 겹쳐서, 그 구간 값은 두 곡선의 공통값일 수 있습니다.
- **Tc(약 120~125 °C) 위**는 모든 곡선이 겹치기 때문에 공통 곡선 하나로 읽었습니다.
- 원본 이미지가 저해상도 스캔이라, 더 큰 이미지를 쓰면 오차가 줄어듭니다.
- 그림은 출판된 논문에서 가져온 것입니다. 저장소를 공개할 때는 저작권에 주의하세요.

## 새 흑백 그래프에 쓰려면

1. **이미지 넣기:** 그래프 이미지를 이 폴더에 넣습니다.
2. **축 보정 (`calib.py`):** `PANELS`에 새 항목을 추가합니다.
   - 파일 이름
   - x축 눈금의 `(픽셀 열 위치들, 값들)`
   - y축 눈금의 `(픽셀 행 위치들, 값들)`
   - 그래프 영역 `(top, bottom, left, right)`

   `python calib.py`를 실행하면 맞춤 잔차가 출력됩니다.
3. **곡선 경로 (`curves_*.py`):** 새 파일에 곡선마다 다음을 적습니다.
   - `guide`: **k배 확대한 crop 이미지 기준 좌표** `(X, Y)`의 꺾은선. crop 원점은 `(left-2, top-2)`
   - `mode`: `'x'`(보통) 또는 `'y'`(거의 수직인 구간)
   - `W`: 가이드 위아래로 찾을 폭(원본 px). 곡선이 가까이 붙어 있으면 3, 떨어져 있으면 5 정도
   - `ignore`: 라벨, 화살표 영역 `(row0, row1, col0, col1)`. **원본 px 기준**
4. **실행:** `make_excel.py`의 `JOBS`에 새 그래프를 추가하고 실행합니다.
5. **확인:** `검증_*.png`를 보고, 어긋난 곳이 있으면 그 부분의 가이드를 고쳐서 다시 실행합니다.

> 참고: 파일 이름 `trace.py`는 파이썬 표준 모듈 `trace`와 이름이 같습니다.
> 그래서 스크립트들은 `sys.path.insert(0, '.')`로 이 폴더를 먼저 찾게 해 두었습니다. **이 폴더 안에서 실행하세요.**
